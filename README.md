## Start here

- **[sky130-8x8-6t-sram-macro](https://github.com/Louayalarfi/sky130-8x8-6t-sram-macro)**, full custom
  8x8 6T SRAM macro in the open source SkyWater Sky130 130 nm process, built bottom up from the bit
  cell, DRC clean in Magic with a bit exact addressed write and read verified in ngspice.
- **[engg4560-de1soc-aes-coprocessor](https://github.com/Louayalarfi/engg4560-de1soc-aes-coprocessor)**, AES 128 encryption coprocessor in the FPGA fabric of an Intel DE1 SoC, memory mapped over the
  lightweight Avalon bridge and driven from embedded Linux on the ARM Cortex A9 HPS.
- **[engg4550-vlsi-digital-design](https://github.com/Louayalarfi/engg4550-vlsi-digital-design)**, 8 bit datapath (adder, multiplexer, register) designed bottom up from 1 bit cells in Cadence
  Virtuoso, with schematic capture, functional tests and delay analysis at every level.
- **[engg3050-embedded-reconfigurable-computing](https://github.com/Louayalarfi/engg3050-embedded-reconfigurable-computing)**, VHDL on Xilinx Vivado and a Zynq ZedBoard, including a carry lookahead adder with a testbench and
  timing constraints, plus the same mini project implemented again in high level synthesis.
- **[engg4420-realtime-systems](https://github.com/Louayalarfi/engg4420-realtime-systems)**, multitasking firmware on an STM32 ARM Cortex M target, built twice on two kernels, FreeRTOS and
  uC/OS III, covering task scheduling, synchronization and a USB virtual COM port.
- **[portfolio](https://github.com/Louayalarfi/portfolio)**, source for lauaialerfi.com, an
  interactive 3D portfolio in Three.js and Vite that zooms into a machine, with a plain page kept
  as the fallback.
